Конвертер валют (Currency Converter)
Графическое приложение для конвертации валют с использованием внешнего API, сохранением истории операций в JSON и фильтрацией.
---
Требования
- Python 3.7+
- Библиотеки: `requests` (встроенные `tkinter`, `json`, `os`, `datetime`)
---
Установка и запуск

1. Клонировать репозиторий
git clone https://github.com/KENDZHII/currency-converter.git
cd currency-converter
2. Установить зависимости
pip install requests
3. Запустить приложение
python main.py
