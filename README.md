# Конвертер валют (Currency Converter)

Автор: Иван Кунакужин

Графическое приложение для конвертации валют с использованием внешнего API, сохранением истории операций в JSON и фильтрацией.

🔑 Получение API ключа
Перейдите на exchangerate-api.com

Нажмите "Get Free API Key"

Введите email (не требуется подтверждение)

Скопируйте полученный API ключ

Вставьте его в поле "API Key" в приложении

Нажмите "Сохранить API ключ"

Бесплатные лимиты: 1500 запросов/месяц (достаточно для тестирования)

---

## 📋 Требования

- Python 3.7+
- Библиотеки: `requests` (встроенные `tkinter`, `json`, `os`, `datetime`)

---

## 🚀 Установка и запуск

# 1. Клонировать репозиторий
git clone https://github.com/usernameisalreadytaken0/currency-converter.git
cd currency-converter

# 2. Установить зависимости
pip install requests

# 3. Запустить приложение
python main.py

---

🎯 Функциональность
Основные возможности:
✅ Конвертация между 24+ валютами

✅ Актуальные курсы из внешнего API

✅ Валидация ввода (положительная сумма, числовой формат)

✅ Сохранение истории в JSON

✅ Фильтрация истории по валюте

✅ Экспорт истории

✅ Очистка истории


Интерфейс:
Поле ввода суммы

Выбор валют (из/в) через выпадающий список

Кнопка конвертации

Отображение результата и текущего курса

Таблица истории с фильтрацией
